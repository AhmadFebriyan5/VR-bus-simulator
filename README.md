Simulator busnya ini berbasis Three.js dan WebXR.

## Features

- VR Mode
- Bus Simulator
- Ampera Bridge
- Dashboard
- Speedometer
- Camera Mode

## Controls

- W = Maju
- S = Mundur
- E = Mesin
- H = Klakson
- F = Pintu
- L = Lampu
- C = Kamera

## Tech Stack

- HTML
- CSS
- JavaScript
- Three.js
- WebXR
