
Struktur Modular:

index.html -> file utama
css/style.css -> desain
js/setup.js -> renderer, camera, lighting, WebXR
js/world.js -> jalan, halte, Ampera, gedung, pohon
js/bus.js -> model bus dan dashboard VR
js/ui.js -> HUD, speedometer, pesan UI
js/game.js -> logika game loop, kontrol, fisika

Ini lebih mirip project game sungguhan dan mudah dikembangkan.
